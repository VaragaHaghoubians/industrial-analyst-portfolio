# Power BI page

Run `src/main.py` first. It writes `data/processed/kpi_data.csv`.

The click-by-click build is in [POWER_BI_STEPS.md](POWER_BI_STEPS.md). The page is four cards, one line of daily good units, one bar of scrap rate by machine, and one bar of downtime by reason.

The Python charts in `reports/figures` are the same story if Power BI is not installed.
