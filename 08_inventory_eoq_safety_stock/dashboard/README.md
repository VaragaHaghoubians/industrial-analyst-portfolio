# Optional Excel view

The Python policy is the source of the numbers. Excel is only a way to filter them.

1. Run `src/main.py`.
2. Open `data/processed/inventory_policy.csv` in Excel.
3. Turn the range into a table.
4. Filter `action` to `Reorder now`.
5. Sort `weeks_of_cover` from smallest to largest.

The three reorder SKUs in the published sample are BEARING, SEAL-KIT and HYDRAULIC-HOSE. SUPPORT is the high-stock row.
